# Twinkle Pals: Kids Dress Up — iPad screenshots

Nine numbered RGB PNGs at exactly **2064 × 2752 pixels**, with portrait iPad device frames and real captures of the current Flutter iPad layouts. `preview.png` is a contact sheet for review.

The pastel backgrounds, original avatar stickers, headlines and subtitles match the previous collection. iPad captures use 1032 × 1376 logical pixels, exported at 2×, and are displayed at their original 3:4 aspect ratio inside the tablet frame. No phone screens are stretched into a tablet. Demo progress and saved pals are confined to the capture tool’s mocked storage; production app code is unchanged.

To reproduce captures: `flutter test output/screenshots-ipad-2064x2752/capture_ipad_test.dart`. Then run `render.cjs` using the bundled Node runtime. Editable HTML and dimension/layout verification are included.
