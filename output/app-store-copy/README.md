# App Store Connect English copy

Promotional text: 145/170 characters.
Description: 2154/4000 characters.
Keywords: 100/100 bytes (ASCII).

Paste each .txt file into its corresponding App Store Connect field, without the final file newline. The copy does not rely on either app name because the supplied splash says Twinkle Pals and the current in-app header says Pocket Pals.

Keywords were selected for relevance to the implemented features: dress-up, avatar customization, character creation and mini-games. Search-volume and competition scores were not available. The keyword set assumes these exact words are not already used in your store name or subtitle; adjust repeated words if you add them there.

Feature and ad-access claims come from the project's current README and supplied app screens. No education, ad-free, multiplayer or unlimited-free-content claims are made.

Apple sources, checked October 9, 2026:
- Field limits: https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information
- Keyword and description guidance: https://developer.apple.com/app-store/product-page/

Promotional text does not affect search ranking, according to Apple's product-page guidance. Use keywords, the name and subtitle for discovery, and promotional text for a readable feature pitch.
